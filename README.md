# Voxa Coaching Website

Build a modern, responsive website for a public speaking and communication 

coaching institute called "Voxa Coaching" (replace with real name later).

DESIGN SYSTEM (follow exactly):

- Primary accent: emerald green (#059669 / #10b981)

- Dark navy footer background: #0a0e2e

- Light mint-green section backgrounds: #ecfdf5

- White base background, rounded pill-shaped buttons

- Organic "blob" shaped image containers (irregular rounded corners, 

  not plain rectangles), with a small dotted-pattern decoration near images

- Typography: Poppins or similar clean sans-serif, bold headings in navy, 

  muted slate-gray body text

- Card-based layout for services and testimonials (white cards, subtle 

  shadow, rounded-2xl corners)

- Fully mobile responsive

ANIMATIONS (keep subtle, smooth — not overdone):

- Smooth scroll navigation between sections

- Gentle fade-up reveal when sections enter viewport (once, not repeated)

- Hover transitions on buttons and cards (scale/shadow lift, 200-300ms ease)

- Smooth color transition on nav links and buttons on hover

- Do NOT animate every element — keep it minimal and professional

PAGES & CONTENT:

1. HOME

   - Hero: "Master Public Speaking Skills Today" headline, subtext about 

     transforming confidence and communication, CTA button "Explore Programs"

   - About summary section: founded in 2025, focused on training people to 

     speak with clarity, structure, and confidence — not just theory

   - "We offer the best services" section: Personal Coaching, Group Sessions, 

     Online Resources

   - Services preview cards: Career-Focused Communication, Young Orator 

     Program, Custom Communication Coaching

   - Testimonials section with 3-4 cards (name, role, review) — e.g. MBA 

     student, IT professional, senior manager

   - Newsletter subscribe section

   - CTA section: "Unlock Your Voice. Own the Spotlight." with enroll button

2. ABOUT

   - Founder/coach bio section (20+ years experience helping people find 

     their voice)

   - Mission statement about communication as a life skill, not just a subject

   - CTA to book a session

3. COURSES (list + individual course cards/pages)

   - Career-Focused Communication

   - All-Rounder English

   - Young Author Program

   - Writer's Choice

   - Young Orator

   - Custom Communication Coaching

   Each with: short description, "Learn More" link, icon

4. SERVICES

   - Personal Coaching, Group Workshops, Online Resources — each with 

     description and image

5. GALLERY

   - Grid of session/workshop photos with hover zoom effect

6. BLOG

   - Blog list page with card layout (title, excerpt, date)

7. CONTACT

   - Contact form (name, email, message)

   - Institute locations list (multiple cities)

   - Phone/email contact info

   - Google Maps embed placeholder

FOOTER:

- Dark navy background, logo, quick links, social icons, address, 

  copyright line

Use placeholder professional stock-style imagery for coaches/students 

in coaching/office settings. Keep the whole site light, clean, and fast.
